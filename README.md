## what i actually build

> Distributed systems, backend infrastructure, and security tooling — no frontend, no fluff.

| Project | What it does | Stack |
|---|---|---|
| **[Shruti](https://github.com/devarshganatra/Shruti)** | Distributed audio processing engine — fans out submissions across 4 async workers via RabbitMQ. Zero duplicate task execution even on mid-flight worker failure. Load tested: 50.6 req/s at 108ms avg latency | `Spring Boot 3` `Java 21` `RabbitMQ` `Redis` `PostgreSQL` `MinIO` `Docker` |
